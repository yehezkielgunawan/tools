Package and JavaScript wrapper source:

https://github.com/catdad-experiments/libheif-js

Corresponding Emscripten build source and build instructions:
https://github.com/catdad-experiments/libheif-emscripten/tree/v1.23.5

The upstream library is not modified. To use a modified compatible decoder,
replace libheif-js/libheif-wasm/libheif-bundle.mjs in your local installation
and rebuild this application with pnpm run build. The integration is isolated
in src/tools/image-shared/heic/worker.ts and decoder.ts.
